# Calculating Median Fluorescence Workflow

This folder contains two R markdown files that are specifically written to calculate the median fluorescence of each of the protein variants generated by the experiment in the Plesa Lab. It would need some adaptation at the beginning of each script to adapt it to the workflow of another similar experiment, but it stands as an example of how the output from both the long read and short read files along with FACS experimental data can be used to calculate the median fluorescence. There are 2 steps (R markdown files) used in calculating the median fluorescence.

1. [`Calculate the Median Bin`](calculate_median_bin.Rmd) for each protein variant
2. [`Calculate the Median fluorescence`](calculate_median_fluorescence.Rmd) for each protein variant

## Requirements
- R version 4.5.1
- dplyr
- tidyr
- tidyverse

## File 1: Median Bin R markdown file

### Input Needed
- 1 consensus sequence file
- all starcode output files for 1 experimental condition
- starcode output from the presorted data
- know the expected barcode length

### Workflow 
1. Read in collapsed barcode data files
2. Join the data and replace NAs with 0s
3. Filter barcodes by the expected barcode length
4. Calculate relative abundance
5. Load consensus output data
6. Keep only the barcodes seen in the consensus data
7. Merge with presort data and update barcodes not seen in presort data to 0.1 counts
8. Calculate the fold change
9. Calculate the adjusted abundance
10. Calculate the median bin value
11. Output the data for the next R markdown script (calculating median fluorescence)

## File 2: Median Fluorescence R markdown file

### Input Needed
- median bin data for all experimental conditions including control conditions
- 1 consensus sequence file (same as before)
- file(s) with the bin number on the first column and the minimum fluorescence in which the FACS sorter used to sort cells into that bin for each condition 
    - Note: These minimum fluorescent values may or may not be different across experimental conditions. In the ['example bins to MEFL file'](bins_to_MEFL_example.tsv), there are only 2 files for the 3 conditions. There is one file for the negative control and one file for both the positive control and the test condition.
- know the WT amino acid sequence

### Workflow
1. Read in the median bin data outputted from the previous median bin R markdown file for all conditions including controls
2. Filter barcodes with low total reads (threshold here is set to 25 in the example script)
3. Load the consensus output data and merge the ligand conditions
4. Load the bin fluorescence data and convert to MEFL
5. Filter by the WT sequence 
6. Calculate the median MEFL for the WT in all experimental conditions
7. Normalize by the WT fluorescence and then by the negative control condition
8. Write results out to 1 file

The final output file from this file can then be used for downstream analysis like hypothesis testing to determine experiment findings.
